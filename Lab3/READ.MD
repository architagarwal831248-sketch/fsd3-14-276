HTTP- HYPER TEXT TRANSFER PROTOCOL
HTML - HYPER TEXT MARKUP LANGUAGE
CSS - CASCADING STYLE SHEET
NPM - NODE PACKAGE MANAGER
ctrl + c to terminate the server

## STATUS CODE
-200 -> OK
-201 ->CREATED
-202 ->ACCEPTED
-204 ->NO CONTENT
-400 ->BAD REQUEST
-401 ->UNAUTHORIZED
-403 ->FORBIDDEN
-404-> NOT FOUND
-500 -> INTERNAL SERVER ERROR
-503 ->SERVICE UNAVAILABLE

## Server can send data
1. html content
2. html files
3. json data
4. plain text
5. css
6. jss
7. file

1. res,writeHeader( )
2. res.setHeader

1. res.statusCode( )
2. res.writeHeader( )
